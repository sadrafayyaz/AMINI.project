# AMINI

A lightweight Persian hardware encyclopedia covering:

- CPU
- GPU
- Semiconductor Lithography

## Technology

- HTML
- CSS
- Vanilla JavaScript

No framework.
No backend.
No database.
No external dependencies.

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html` and `README.md`.
3. Open:

   Settings → Pages

4. Select:

   Deploy from a branch

5. Select:

   main / root

6. Save.

The site will then be available through GitHub Pages.
